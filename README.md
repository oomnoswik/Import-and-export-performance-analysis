# 🔬 L-아르기닌(L-Arginine) 관세청 3대 무역통계 통합 분석 대시보드

공공데이터포털(**data.go.kr**)의 관세청 3대 무역통계 OpenAPI를 연동하여, **L-아르기닌(HS Code: 2925.29 / 2925.29.1000)**의 연도별·월별 수출입 동향뿐만 아니라 **"국내 특정 시군구에서 해외 어느 국가로 얼마나 수출되었는지"**를 입체적으로 분석할 수 있는 **프리미엄 반응형 무역 분석 시스템**입니다.

---

## 📌 연동된 관세청 3대 OpenAPI

1. **관세청_품목별 국가별 수출입실적(GW)** (`apis.data.go.kr/1220000/nitemtrade`)
   - 품목(HS Code)별 월별·연도별 통관 실적 (수출액, 수입액, 중량, 단가 $/kg)
2. **관세청_국가별 수출입실적(GW)** (`apis.data.go.kr/1220000/nationtrade`)
   - 국가별 한국 전체 총무역 통계 및 품목별 교역 침투율
3. **관세청_시군구별 품목별 수출입실적** (`apis.data.go.kr/1220000/sigunguitemtrade`)
   - 국내 시군구(충북 청주, 경기 화성, 전북 군산, 인천 연수 등) ⟷ L-아르기닌 ⟷ 해외 수출 대상국(미국, 베트남, 일본 등) 통관 실적

---

## 🚀 실행 및 접속 방법

```bash
python server.py
```

👉 웹 브라우저 접속: **[http://localhost:8000](http://localhost:8000)**

## 🗺️ 주요 분석 화면

- **📊 종합 대시보드**: KPI 핵심 지표, 연도별 콤보 차트, 점유율 도넛 차트, 단가 스프레드
- **🗺️ 국내 시군구별 수출입 & 해외 대상국 분석 (핵심 신규)**:
  - 국내 시군구 선택 시 해당 지역에서 생산된 L-아르기닌의 **해외 수출 대상국 랭킹 및 수출액($M)·비중(%)·평균단가($/kg)** 즉시 산출
- **📈 연도별·월별 시계열 분석**: 장기 연속 시계열 및 월별 모멘텀
- **⚖️ 단가 & 부가가치 마진 분석**: 수출단가 vs 수입단가 비교
- **🌍 글로벌 교역국 분석**: Top 8 수출국/수입국 랭킹 및 상세 매트릭스
- **📅 계절성 & 월별 패턴**: 12개월 레이더 차트
- **🧠 AI 스마트 비즈니스 진단**: 실시간 데이터 기반 경영 전략 제언
- **📋 전체 원본 데이터**: 검색, 정렬, 페이지네이션 및 CSV 엑셀 다운로드
